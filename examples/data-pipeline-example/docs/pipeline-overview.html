SPEC file pattern — how it works
When required

ROW_NUMBER() RANK() SUM() OVER LAG / LEAD Dedup logic UDF call CASE 3+ branches Pivot / unpivot Recursive CTE 4+ CTE chain

Structure

Header: BEHAVIOUR · INPUT · EXPECTED OUTPUT · EDGE CASES

Query: input_fixture (literal VALUES) → actual (logic under test) → expected (literal VALUES) → mismatches (FULL OUTER JOIN)

Pass: query returns 0 rows
Fail: any row returned = diff between actual and expected
