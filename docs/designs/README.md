# Design Documents

This folder contains design specs produced by the `brainstorming` skill.

## Naming Convention

```
YYYY-MM-DD-<topic>-design.md
```

## Examples

```
2026-04-01-user-authentication-design.md
2026-04-15-file-upload-service-design.md
```

## Lifecycle

1. **Draft** — created during brainstorming session, reviewed by team
2. **Approved** — user confirms design before implementation plan is created
3. **Superseded** — replaced by a newer design (keep old file, add note at top)

Design docs are inputs to `writing-plans`. Every implementation plan must link to a design doc.
