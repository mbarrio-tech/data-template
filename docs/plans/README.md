# Implementation Plans

This folder contains implementation plans produced by the `writing-plans` skill.

## Naming Convention

```
YYYY-MM-DD-<feature-name>.md
```

## Examples

```
2026-04-01-user-authentication.md
2026-04-15-file-upload-service.md
```

## Lifecycle

1. **Active** — currently being executed via `subagent-driven-development`
2. **Complete** — all tasks checked off, branch merged or PR opened
3. **Abandoned** — work stopped (add note at top explaining why)

Each plan links to its corresponding design doc in `docs/designs/` and to the polaris.md deliverable it serves.
